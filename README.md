# Google OAuth Demo

## Setup

1. Install dependencies:

   ```bash
   npm install
   ```

2. Copy `.env.example` to `.env` and add your Google OAuth credentials.
3. Add the callback URL from `CALLBACK_URL` to your Google OAuth client.
4. Start the app:

   ```bash
   npm start
   ```

Open <http://localhost:3003> and choose **Login with google**.
